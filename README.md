## ✨ Features
- Menu & stock management
- Real-time orders
- Payment confirmation
- Admin dashboard

## 🛠️ Tech Stack
- React
- Hono
- Prisma
- Websock
- PostgreSQL

## 📂 Setup

1. Install dependencies
npm install

2. Create .env in backend
DATABASE_URL=your_postgres_url

3. Run backend
npm run dev

4. Run frontend
npm start
